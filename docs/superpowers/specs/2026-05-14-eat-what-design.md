# 吃什么小程序 - 设计文档

> 日期：2026-05-14 | 状态：待实现

## 概述

一款微信小程序，帮助用户决定"今天吃什么"。核心功能：根据天气推荐菜品、随机生成菜品、上传菜单照片 OCR 识别后随机选择。

## 技术方案

纯前端 + 本地存储方案，无需后端服务器。

| 项 | 选择 |
|---|------|
| 平台 | 微信小程序（原生开发） |
| 语言 | TypeScript |
| 天气 API | 和风天气 API 免费版 |
| OCR | 微信云开发 OCR（基础版免费额度） |
| 位置 | `wx.getLocation` |
| 存储 | 本地 Storage（历史记录、偏好设置） |

## 页面结构

### 1. 首页（index）

- **天气栏**：获取用户位置，展示当前天气（温度、图标、描述）
- **推荐卡片**：根据天气规则推荐 1-2 个菜品
- **随机按钮**：圆形黑色按钮「随机吃什么」，点击弹出结果弹窗
- **分类标签**：面食 / 米饭 / 炖菜 / 凉拌，用于快速筛选随机范围
- **结果弹窗**：居中弹窗展示随机菜品（菜名、emoji、标签、烹饪时间/难度），底部「换一个」和「就这个」两个按钮

### 2. 扫菜单（ocr）

- **空态引导**：虚线边框区域，拍照/相册两个入口按钮
- **识别中**：loading 动画 + 提示文字
- **识别结果**：菜品标签列表，可编辑（删除/修改/添加），底部「帮我选一个」按钮
- **随机结果**：从识别出的菜品中均匀随机，弹窗展示结果

### 3. 历史记录（history）

- 按时间倒序展示历史随机记录
- 每条记录显示：菜品名、时间、来源（天气推荐/随机/菜单识别）
- 点击可查看菜品详情

### 4. 我的（profile）

- 用户头像昵称展示
- 偏好设置入口（口味偏好、忌口食材）
- 历史记录入口 → 跳转 history 页面
- 关于我们、反馈建议

## 数据模型

```typescript
// 菜品
{
  id: string,
  name: string,           // "番茄鸡蛋面"
  category: string,       // noodle | rice | stew | cold | soup | stirfry | snack
  suitableWeather: [],    // rainy | hot | cold | mild
  cookingTime: number,    // 分钟
  difficulty: string,     // easy | medium | hard
  tags: [],               // ["家常", "下饭", "快手"]
  emoji: string           // "🍜"
}

// 历史记录
{
  id: string,
  dishId: string,
  dishName: string,
  source: string,         // weather | random | ocr
  weather: string,        // 当时的天气描述（可选）
  createdAt: timestamp
}
```

## 天气推荐规则

| 天气类型 | 判断条件 | 推荐策略 |
|---------|---------|---------|
| 雨天 | 天气码含 rain/drizzle | 优先汤面、煲类、热汤 |
| 热天 | 温度 > 30°C | 优先凉菜、沙拉、轻食 |
| 冷天 | 温度 < 10°C | 优先炖菜、火锅、煲类 |
| 温和 | 其他 | 从全库随机 |

## 随机算法

### 首页随机

加权随机：匹配当前天气的菜品权重 1.5，不匹配的权重 1.0。如果用户选择了分类标签，仅在该分类范围内随机。

### 菜单 OCR 随机

从识别出的菜品列表中均匀随机选取。

## 内置菜谱库

初始内置约 30-50 道家常菜品，覆盖各大菜系和常见类别。菜品数据存于 `utils/recipe-data.ts`。

## 视觉风格

- **简约清爽**：白底为主，大面积留白
- **配色**：浅灰（#f5f7fa）卡片背景、深色（#333）文字、黑色主按钮
- **圆角**：卡片 12px、标签 20px/8px
- **字体**：系统默认，信息层级靠字号和粗细区分

## 页面流程

```
首页 → 查看天气推荐 → 点「随机」→ 弹窗展示结果（换一个 / 就这个）
                                           ↓ 确认 → 记入历史

扫菜单 → 拍照/相册 → OCR 识别 → 编辑菜品列表 → 点「帮我选」→ 随机选中
                                                              ↓ 记入历史

我的 → 偏好设置 / 历史记录 → 历史记录列表 / 关于
```
