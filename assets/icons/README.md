# TabBar Icons

需要 8 个 81x81 像素的 PNG 图标文件：

| 文件名 | 用途 | 建议图标 |
|--------|------|---------|
| home.png | 首页（默认） | 房子轮廓 |
| home-active.png | 首页（选中） | 实心房子 |
| scan.png | 扫菜单（默认） | 相机轮廓 |
| scan-active.png | 扫菜单（选中） | 实心相机 |
| history.png | 历史（默认） | 时钟轮廓 |
| history-active.png | 历史（选中） | 实心时钟 |
| profile.png | 我的（默认） | 人物轮廓 |
| profile-active.png | 我的（选中） | 实心人物 |

**获取方式：**
1. 使用微信开发者工具右键 app.json → "添加 TabBar 图标" 自动生成
2. 或从 iconfont.cn 下载
3. 或使用 Figma/Sketch 自行设计

**颜色规范：**
- 默认（未选中）：#999999
- 选中：#333333
